# Phase 3 – Linux server and Wazuh SIEM

By the end of this phase, an Ubuntu server (LNX01) runs the Wazuh SIEM, DC01 and WS01 send their security logs to it, and simulated attacks show up as MITRE-mapped alerts.

## 1. Create LNX01

| Setting | Value |
| --- | --- |
| Image | Ubuntu Server 24.04 LTS (x64 Gen2) |
| Size | Standard_B2as_v2 (2 vCPU, 8 GiB). Wazuh needs 8 GB of memory |
| Authentication | SSH public key, Ed25519, generated by Azure (`lnx01_key.pem`) |
| Disk | 64 GiB, Standard SSD **LRS** |
| Network | `vnet-homelab` / `snet-servers`, static private IP `10.10.1.5` |
| NSG | SSH (22) and HTTPS (443) from my IP only |
| Other | Auto-shutdown 11 PM |

> ⚠️ The VM wizard defaulted to a **new** virtual network and **ZRS** disks. Check the Review tab for `(new)` before creating.

## 2. Connect over SSH (Mac)

```bash
mkdir -p ~/.ssh && mv ~/Downloads/lnx01_key.pem ~/.ssh/
chmod 400 ~/.ssh/lnx01_key.pem
ssh -i ~/.ssh/lnx01_key.pem labadmin@<LNX01 public IP>
```

## 3. Install Wazuh (all-in-one)

```bash
sudo apt update && sudo apt -y upgrade
curl -sO https://packages.wazuh.com/4.14/wazuh-install.sh && sudo bash ./wazuh-install.sh -a
```

On 2 vCPUs this took about 20 minutes. Save the `admin` password from the summary, then open `https://<LNX01 public IP>` and accept the self-signed certificate warning.

## 4. Enroll agents

Dashboard → **Agents management → Deploy new agent** → Windows MSI, server address **`10.10.1.5`** (private IP, same virtual network), agent name `DC01` / `WS01`. Run the generated `Invoke-WebRequest ... msiexec` command in an elevated PowerShell on each machine, then `NET START Wazuh`. Both agents showed **Active** within a minute. LNX01 monitors itself.

## 5. Simulate attacks

| Attack | How |
| --- | --- |
| RDP brute force | 8 wrong passwords for `HOMELAB\nina.lopez` |
| SSH probing | `ssh admin@`, `ssh root@`, `ssh test@` LNX01 from the Mac |
| Backdoor admin | `New-ADUser svc_backup ...` then `Add-ADGroupMember "Domain Admins" -Members svc_backup` on DC01 |
| Covering tracks | `wevtutil cl Security` on WS01 |

## 6. Hunt in Wazuh

**Threat intelligence → Threat Hunting → Events**, last hour. These queries cut the noise:

```text
rule.level >= 5
rule.mitre.id:*
rule.mitre.id:* and rule.level > 3
```

The last one narrowed 1,600+ events to 15 alerts. Full write-up: [incident report](incident-report-2026-11-18.md).

## 7. Clean up

```powershell
Remove-ADUser svc_backup -Confirm:$false
Unlock-ADAccount nina.lopez
```

Stop **LNX01**, **WS01**, then **DC01**.
